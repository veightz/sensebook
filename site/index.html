Sensebook

油猴脚本

语境划词生词本

在网页里划词，连同整句语境一起翻译、存进生词本并释义。读到哪、在哪个句子里遇到，都留着。

  • 翻译 / 存本并释义由 DeepSeek 完成，API Key 只存在你本机的脚本存储里，不上传、不写进任何仓库。
  • 静默按钮弹框打扰时一键静音：15 秒 / 30 秒 / 5 分钟 / 自定义，还有「静到刷新」。
  • 按长度选提示词单词与长句用不同的提示词；先出音标和本地释义，再等模型回答。
  • 安卓 / Mac 骨架原生端的工程骨架已在同一仓库中，后续接同步。

MarkDone Lite

油猴脚本

ChatGPT 阅读增强（轻量版）

基于开源项目 AI-MarkDone 的我们自己的分支，只留日常真正用得上的几样。

  • 阅读器跟人走打开你正在看的那条回答，切换时只认当前激活的页面。
  • 大纲钉住阅读器右侧的大纲可以用 📌 固定。
  • 页面宽度标准 / 较宽 / 铺满，三档循环并记住。
  • 软刷新不整页重载，直接重新识别当前对话。
