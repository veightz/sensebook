# Sensebook 个人版 V1

## 目标
查询入口留在电脑脚本与 Android；响应式网站汇总查询经历并按需生成日/周/月回顾。默认免登录、本地优先，同步必须主动开启。个人使用，优先 Cloudflare 免费额度。

## 用户流程
1. 划词查询先保存本地事件，再写入实际解释或失败状态；重复查询仍可记录，网络重试不重复创建。
2. 网站登录与设备同步分开。用户在网站创建设备连接凭据，在脚本/Android 开启同步，并主动选择导入旧记录或仅同步新查询。
3. 网站历史按时间展示原句、来源和设备，支持搜索、收藏、删除。
4. 网站选日/周/月：已有回顾直接读；没有回顾时用账号默认模型配置生成（保留本机临时 Key 模式）；补传记录后可更新回顾。
5. 账号保存多个 OpenAI 兼容模型配置（名称、Base URL、模型、API Key、思考开关），选择一个默认配置。API Key 用站点独立 Secret 做 AES-GCM 加密后存 D1；列表仅掩码。网站登录后自动选用账号默认配置，已连接的脚本和 Android 自动获取默认配置，无需再次复制 Key。
6. 查询记录同步与模型配置同步分别开关；本地翻译仍可独立使用。关闭模型同步保留当前本机配置；删除云端默认配置时清除由云端托管的本机 Key，手动本机配置不受影响。撤销设备只能阻止后续读取，无法收回已下载到离线端的 Key。

## 边界
- 不公开注册、不收费、不自动定时调用 AI；不根据查询频率推断掌握程度。
- Android 没有原句时保留空上下文，不编造原句或网址。
- 旧缓存/生词本导入标记 legacy，不能还原历史查询次数。
- 网站账号使用 Cloudflare Access 个人邮箱认证（已确认）；本地预览可显式启用 loopback 开发身份，生产默认拒绝未配置认证。

## 验收
- 缓存命中、新查询、失败均有独立事件；关闭云端不影响翻译。
- 重试幂等、删除不复活、设备撤销后不能再上传；各用户隔离。
- 网站桌面/手机可读；无数据、加载、失败可恢复；回顾来源可查看。
- Workers + D1 本地集成测试通过；部署说明可执行，免费版无付费依赖。
